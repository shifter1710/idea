# Правила расчёта калькулятора

Этот файл фиксирует правила из исходного текста таблиц оценки результатов, чтобы они не терялись при сбросе контекста и использовались как источник требований для проекта.

## Нормативные правила

1. Если точного результата нет в таблице, берётся ближайший худший результат, а не ближайший по модулю.
2. Для беговых дисциплин "худший" результат означает большее время.
3. Для технических дисциплин "худший" результат означает меньшую дальность или высоту.
4. Пример из текста: в беге на 5000 м результат `13.05,50` оценивается как `13.05,62` и получает `1201` очко.
5. Пример из текста: в метании молота результат `77,68` оценивается как `77,65` и получает `1113` очков.
6. Если результат превышает верхний предел таблицы (`1500` очков), оценка считается последовательным добавлением очков к верхнему табличному значению по последнему значимому интервалу.
7. Пример из текста: метание диска у мужчин `80,42` = `1500` очков за `79,80` плюс по `1` очку за каждые следующие `3` см, итого `1520` очков.
8. Основные таблицы для бега рассчитаны для автохронометража.
9. Для ручного хронометража нужно использовать дополнительные таблицы, а не основные.
10. Для бега на `1000` м и длиннее допускается пользоваться одной таблицей, потому что различие между ручным и электронным хронометрированием считается незначительным.

## Статус реализации в проекте

На текущий момент веб-калькулятор в проекте реализован так:

- для текущих беговых шкал калькулятор выбирает ближайший худший результат из таблицы;
- если введённый результат хуже нижней границы таблицы, возвращается нижняя табличная строка;
- экстраполяция выше верхнего предела таблицы реализована только для монотонной верхней части шкалы;
- если верх шкалы в БД противоречив или явно испорчен OCR/ручными правками, экстраполяция отключается защитой, и калькулятор остаётся в рамках табличного подбора;
- разделение логики для автохронометража и ручного хронометража пока не реализовано в веб-калькуляторе, потому что текущая веб-БД содержит только шкалы `auto`.

## Что считать правильным поведением при доработке

- Для дисциплин на время нужно выбирать табличный результат, который не лучше введённого спортсменом времени.
- Для дисциплин на дальность/высоту нужно выбирать табличный результат, который не лучше введённого достижения.
- Если результат лучше верхнего предела таблицы, нужно продолжать счёт от `1500` очков шагом последнего значимого интервала данной шкалы.
- Для беговых дисциплин нужно явно учитывать тип хронометража, кроме дистанций `1000` м и длиннее, где может использоваться одна таблица.
